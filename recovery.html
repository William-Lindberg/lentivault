Recovery guide

Calm, practical steps for when something does not work as expected.

Emergency calls always work. The phone dialer and emergency information are never blocked, and every block screen has an Emergency call button. You can also call from the lock screen as usual.

A restriction shows "Permission missing" or "Enforcement interrupted"

  1. Open Lentivault → Settings → Permissions. Every missing item has a button that opens the right system screen.
  2. Check Accessibility is on for Lentivault, and Usage access is allowed.
  3. On Android 13+, if the accessibility switch is greyed out, follow the Allow restricted settings steps.
  4. Set battery use to Unrestricted if your phone stops background services.

An app is blocked and you did not expect it

  • The block screen shows which rule is responsible and when it ends.
  • Open Lentivault → Schedules to see all rules on a timeline; overlapping rules are explained there.
  • Rules from Gentle, Mindful and Firm modes can be paused or edited in the app. Strict and Maximum commitments can be ended early through their delayed request. Ultra Extreme cannot be ended from inside the app.

The time looks wrong

  • Turn on automatic date and time and automatic time zone in Android Settings.
  • Commitments keep the time zone they started in, and their end times are shown in that zone.
  • If you changed the clock by hand, Lentivault notices and keeps counting real time, so the block does not end early. It returns to normal once the clock is correct.

How a commitment ends through Android itself

Lentivault is designed so that you cannot weaken a commitment from inside the app. Android, however, always leaves the phone’s owner in control. These system actions end Lentivault’s enforcement on that device. They are listed here so you know your options in an emergency or if something goes wrong, not as a recommendation:

  • Turn off the accessibility service: Settings → Accessibility → Lentivault → off. Blocking stops immediately; tracking continues.
  • Safe mode: restarting in safe mode (the method differs per phone) starts Android without third-party apps, so no blocking applies until a normal restart.
  • Uninstall: Settings → Apps → Lentivault → Uninstall. If you turned on uninstall friction, first turn off Lentivault under Settings → Security → Device admin apps. Uninstalling deletes all Lentivault data.

Lentivault records an interruption in the commitment’s audit trail when it notices one. The commitment’s timer keeps running; turning the service back on does not extend it.

In the browser extension

  • Removing or disabling the extension on the browser’s extensions page ends its enforcement in that browser.
  • If a site looks broken, feed hiding may not match a recent site change: turn off feed hiding for that site in the extension’s options.

Moving to a new phone

  1. On the old phone: Settings → Data → Export (JSON).
  2. Install Lentivault on the new phone and choose Import during setup or in Settings → Data.
  3. Grant the permissions again. Commitments that are still running continue with the same end times.

Reset everything

Settings → Data → Delete all data. This is always allowed. If a commitment is running, the enforcement already handed to Android keeps the current cycle in place until it ends; the app explains this before you confirm.

If you are struggling

Lentivault is a tool for managing screen time; it is not a medical or therapeutic service. If your phone use is causing you real distress, talking to someone you trust or a healthcare professional can help.
