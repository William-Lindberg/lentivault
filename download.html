Download

Free, no account needed. Choose your device.

Android (8.0 or newer)

Download the APK

Lentivault is not on Google Play yet, so it is installed from a file ("sideloading"). The SHA-256 checksum is published with each release so you can check the file.

Install

  1. Download the APK on your phone and open it from the notification or your Downloads.
  2. If Android asks, allow Install unknown apps for the browser or file manager you used, then go back and tap Install.
  3. Google Play Protect may show a warning for apps from outside the Play Store. Choose to install only if you downloaded the file from this site.
  4. Open Lentivault. The setup takes about a minute and explains each permission before asking.

Allow usage access

  1. Lentivault opens Settings → Usage access (sometimes under Apps → Special app access).
  2. Tap Lentivault and turn on Permit usage access.

Turn on the accessibility service (Android 13 and newer: allow restricted settings first)

Android 13 and newer protect accessibility settings for apps installed from a file. You allow them once:

  1. In Settings → Accessibility, tap Lentivault. If the switch is greyed out or you see Restricted setting, tap OK.
  2. Open Settings → Apps → Lentivault (App info).
  3. Tap the ⋮ menu in the top-right corner and choose Allow restricted settings. Confirm with your PIN, pattern or fingerprint.
  4. Go back to Settings → Accessibility → Lentivault and turn it on. Android explains what the service can see; Lentivault uses it only to know which app is in front, show the block screen and read browser address bars for your website rules.

Menu names differ a little between manufacturers. On some phones the accessibility list is under Installed apps or Downloaded apps.

Recommended on some phones

  • Set Lentivault’s battery use to Unrestricted (Settings → Apps → Lentivault → Battery). Some manufacturers otherwise stop background services.
  • Allow notifications if you want reminders and renewal deadlines.

Browser extension

Blocks sites, sets per-site time limits and hides feeds. It is not in the browser stores yet, so you install it from a file.

Download for Chrome, Edge, Brave, Opera Download for Firefox

Chrome, Edge, Brave, Opera

  1. Unzip the downloaded file into a folder you will keep (the browser loads it from there).
  2. Open the extensions page: chrome://extensions, edge://extensions, brave://extensions or opera://extensions.
  3. Turn on Developer mode (a switch at the top right, or in the left sidebar in Edge).
  4. Click Load unpacked and choose the unzipped folder.
  5. Optional: under the extension’s Details, allow it in private/incognito windows so rules apply there too.

The browser may remind you that a developer-mode extension is installed. That is expected for extensions not installed from a store.

Firefox (128 or newer)

  1. Open about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on… and choose the downloaded zip file (or its manifest.json after unzipping).
  3. In about:addons → Lentivault → Permissions, allow access to all websites, otherwise blocking and feed hiding cannot work.

Firefox removes a temporary add-on when it closes. Permanent installation in the release version of Firefox requires a Mozilla-signed file; when a signed version is published it will be offered here. Firefox Developer Edition and Nightly can install unsigned add-ons if xpinstall.signatures.required is set to false in about:config.

Web app

Works in any modern browser for planning, focus timers and trying Lentivault with demo data. It cannot track or block other apps; it tells you so where it matters.

Open the web app

iPhone and iPad

Not available yet. Blocking apps on iOS requires Apple’s Family Controls entitlement and a native app; see capabilities. The web app works in Safari.
